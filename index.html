DoneSignal — Privacy Policy

Effective October 30, 2026

Developer contact: mailsudeep99@gmail.com

DoneSignal is a Chrome extension for remembering browser tasks, detecting user-specified completion clues, and confirming finished work.

Information handled

DoneSignal saves task titles, a page URL selected by the user, optional success phrases or URL clues, task statuses, and timestamps. For detected clues, it saves a website origin and page path as a local completion reference. The chosen resume link may include URL query parameters. Users should avoid saving links containing sensitive access tokens or other secrets.

When the user explicitly enables automatic clue detection on a website, DoneSignal checks visible page text, the page title, or its URL locally against the clue provided. It does not save or transmit full page content, form fields, passwords, messages, or a full browsing-history log.

How data is used

Stored website links are limited to pages the user deliberately saves as tasks and page paths where a completion clue is detected; DoneSignal does not read the browser's history database.

Task data is used only to display tasks, allow users to resume unfinished work, check chosen completion clues on authorized websites, and help users confirm finished work.

Local storage and sharing

Data is stored using Chrome's local extension storage (chrome.storage.local). Version 1.0.2 has no external servers, third-party analytics, advertisements, user accounts, or AI integrations. DoneSignal does not upload task information, browsing activity, or website content to the developer or any third party.

Permissions

  • activeTab: Reads the current tab address when the user opens DoneSignal to prefill a resume URL.
  • storage: Saves tasks and status locally.
  • scripting: Runs local clue checks on approved websites.
  • Optional website access: Requested per site only when the user turns on automatic clue detection.

Control and retention

Users can delete tasks at any time and revoke website permissions in Chrome extension settings. Deleting a task removes its local record. Chrome may remove local extension storage after uninstall. DoneSignal does not sync task data between devices.

Changes

This policy and store disclosures will be updated if the extension's data practices change.
